🏰 How to Play

The Method of Loci:

By anchoring each object to a specific location (e.g. "The Ancient Spellbook is in the Royal Library"), your brain creates vivid spatial memories that are easy to recall.

• Phase 1 (Memorization): Carefully observe the 3 relics in each room.
• Phase 2 (Restoration): Drag each item or tap an item and then tap the matching room.
• Tip: If 6 rooms feels overwhelming, try Room by Room mode for a focused learning experience!
